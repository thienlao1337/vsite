# наш маленький мир ♡

Небольшая интерактивная открытка в честь **одного месяца общения**. Пять звёздочек, чёрный кошкомальчик Хитрик, золотистый котик-рыцарь, зайка Биби и личное письмо в секретном саду. Полноценный статический сайт: регистрация, сервер, база данных и ключи API не нужны.

## Запуск

Нужен Node.js **22.12+** (подходит также 24).

```sh
npm ci
npm run dev
```

Vite выводит адрес разработки. Сайт доступен с телефона в одной сети с компьютером при подходящих настройках сети. Команды выполняются из корня проекта (`/workspace/vsite` в текущем окружении).

```sh
npm run build   # TypeScript + production-сборка в dist/
npm run preview # локальная проверка production-сборки
```

## Всё личное — в одном файле

Откройте **[src/config.ts](src/config.ts)**. Пустые поля безопасны: сайт использует нейтральное обращение, иллюстрации и текстовые карточки, не придумывая имя или дату.

| Поле                          | Что изменить                                                                                                              |
| ----------------------------- | ------------------------------------------------------------------------------------------------------------------------- |
| `femboyStyle` / `vocabulary`  | Наряд Хитрика (юбочка, гольфы, бантик), клуб хитриков и словечки «няшить», «хитруня».                                     |
| `catName` / `catAppearance`   | Имя и окраска котика — сейчас Хитрик, чёрный котик с золотыми глазами.                                                    |
| `girlName`                    | Имя получательницы. Пустая строка — обращение из `girlNickname` (сейчас «моя госпожа»).                                   |
| `girlNickname` / `senderRole` | Ваши обращения и роли. Полный текст подписи задаётся отдельно в `senderName`.                                             |
| `knightName` / `arcade`       | Имя персонажа по референсу, тексты игрового уголка, его видимость (`enabled`) и цель три в ряд (`matchGoal`).             |
| `senderName`                  | Подпись внизу главного письма.                                                                                            |
| `startDate`                   | Настоящая дата знакомства в формате `YYYY-MM-DD`. Пустая строка скрывает числовой счётчик.                                |
| `timeZone`                    | Часовой пояс IANA, например `Europe/Budapest`. Дата трактуется как полночь в этом поясе; учитывается летнее время.        |
| `letterText`                  | Основное письмо; разделяйте абзацы пустой строкой.                                                                        |
| `memories`                    | Пять страниц истории знакомства: `label`, `title`, `text`. Текущий текст — нейтральные формулировки, не реальные события. |
| `album`                       | Текстовые страницы альбома.                                                                                               |
| `notes` / `skyNotes`          | Маленькие письма и записки на звёздах.                                                                                    |
| `compliments`                 | Набор комплиментов. Фразы не повторяются до исчерпания набора.                                                            |
| `insideJokes`                 | Ваши шутки; строки автоматически добавляются в альбом.                                                                    |
| `photos`                      | Ваши фотографии, которые будут добавлены после текстовых страниц.                                                         |
| `scenes`                      | `false` скрывает выбранное приключение и исключает его из условий открытия сада. По умолчанию включены все пять.          |
| `musicTheme`                  | `music-box` (шкатулка) или `piano` (ниже по звучанию). Оригинальная мелодия через Web Audio.                              |
| `theme` / `siteTitle`         | Базовая палитра и название вкладки/сайта.                                                                                 |

### Фотографии

Положите изображения в `public/photos/`. Рекомендуется WebP/JPEG до 300–500 КБ, шириной около 1200 px. Например:

```ts
photos: [
  { src: './photos/moment.webp', caption: 'Наш маленький момент', alt: 'Описание фотографии' },
],
```

При ошибке загрузки появится иллюстрированная карточка. Фотографии необязательны. Никогда не добавляйте чужие фото или личную переписку без согласия. **Все файлы и тексты статического сайта публичны**, даже если письмо скрыто игровым прогрессом. Это подарок, а не защищённое хранилище.

### Быстрый пример персонализации

В `src/config.ts` можно заменить, например:

```ts
girlName: 'Её имя',
girlNickname: 'моя госпожа',
senderName: 'твой кошкомальчик Хитрик',
startDate: '', // впишите настоящую дату, а не примерную
letterText: `Ваш собственный текст.

Каждый новый абзац — через пустую строку.`,
```

Имя котика и роль отправителя задаются вверху этого же файла: `const catName = 'Хитрик'` и `const senderRole = 'твой кошкомальчик'`. Тексты обращения в `vocabulary`, письма в `notes`, страницы `memories`/`album` и реплики в `arcade` можно редактировать независимо. Графика меняется в `src/components/Art.tsx`, размеры и оформление — в `src/styles.css`. После изменений посмотрите dev-сервер, затем выполните `npm run build` и заново опубликуйте сборку. Правка файлов **не изменяет уже опубликованный сайт** автоматически, кроме настроенного автодеплоя из GitHub.

### Прогресс и звук

Звёздочки и открытые письма сохраняются в `localStorage` на том же устройстве и в том же браузере. Встроенный браузер Telegram и Safari могут хранить данные отдельно. При запрете хранилища игра остаётся доступной в текущей вкладке и показывает предупреждение. Кнопка «посмотреть всё сначала» просит подтверждение перед сбросом. Аудио изначально выключено; музыку и эффекты можно включить независимо. При сворачивании страницы музыка приостанавливается.

## Дополнительные игры

Игровой уголок доступен с карты сразу, а также из финала. Его прохождение не блокирует главное письмо и не заменяет ни одну из пяти звёзд.

- **Три в ряд:** поле 6×6; выберите две соседние фигурки, чтобы поменять их местами. Совпадения из 3+ исчезают, предметы падают, каскады дают дополнительные очки. Подсказка показывает рабочий ход; перемешивание сохраняет очки. Если ходы закончились, поле обновляется автоматически.
- **Merge:** поле 4×4; выберите или перетащите один предмет на такой же. Два одинаковых превращаются в следующий уровень. Можно переносить находки на пустые клетки и доставать новые из корзинки. Цепочка: сердечко → клубничка → цветок → бантик → кристалл → корона → котик-рыцарь.
- Таймеров, ограниченных жизней, платных предметов и проигрыша нет. Поля и очки сохраняются отдельно в `little-world-arcade-v1`; основной сюжет — в `little-world-v1`. Перезапуск партии сохраняет рекорды и уже найденных рыцарок. Сброс истории не удаляет игровые рекорды.

Золотистый котик-рыцарь — **авторская SVG-интерпретация присланного референса**, с бантиком, плащом, доспехами и мечом. Биби остаётся помощницей в игре с корзинкой.

## Публикация и ссылка

### Vercel

1. Загрузите проект в ваш GitHub-репозиторий.
2. Импортируйте репозиторий в Vercel. Preset: **Vite**, build: `npm run build`, output: `dist`.
3. Нажмите Deploy. Vercel выдаст HTTPS-ссылку.
4. Добавьте переменную сборки `SITE_URL` с полным адресом сайта (например `https://your-gift.vercel.app`) и пересоберите: обложка Open Graph получит абсолютный адрес.

### Netlify

Импортируйте репозиторий. `netlify.toml` уже содержит команду и папку сборки. Можно также загрузить содержимое `dist/` вручную. Для Open Graph при автоматической сборке задайте `SITE_URL` с адресом сайта. При ручной публикации задайте её перед локальной сборкой:

```sh
SITE_URL=https://your-gift.netlify.app npm run build
```

### GitHub Pages

В репозитории откройте **Settings → Pages → Source → GitHub Actions**. Workflow `.github/workflows/pages.yml` собирает и публикует ветку `main`; запускается после push или вручную в Actions. Для текущего репозитория адрес будет `https://thienlao1337.github.io/vsite/`. Если переименуете репозиторий, поправьте `SITE_URL` в workflow. База Vite `./` позволяет загружать ресурсы из подпапки. Включите HTTPS в настройках Pages.

### Превью ссылки

Чтобы обновить иллюстрацию обложки после изменения персонажа, при работающем dev-сервере выполните `npm run cover` (нужен Chromium).

В `public/social-cover.png` — оригинальная обложка 1200×630 с Хитриком и золотистым котиком-рыцарем. В `public/favicon.svg` — котёнок. `index.html` содержит общедоступные нейтральные метаданные. Для корректного превью в мессенджерах после публикации задайте `SITE_URL` и пересоберите проект. Мессенджеры могут кэшировать старую обложку.

**Публикация не выполняется командами разработки.** До отправки откройте полученную HTTPS-ссылку на телефоне. Проверьте Safari и встроенный браузер Telegram, особенно звук после первого нажатия и доступность хранилища.

## Проверки

```sh
npm test
```

Playwright проверяет полный путь по пяти приключениям, игру до 10 предметов, пропуск, письма, альбом, сохранение, сад, главное письмо, отсутствие повторов комплиментов, объятия, сброс, запрещённое хранилище, повреждённые данные и узкую вёрстку. Отдельно проверяется дата и переход летнего времени.

В cloud-среде тесты используют `/usr/bin/chromium`. Для другой установленной версии задайте `CHROMIUM_PATH`. При использовании скачанного Playwright Chromium укажите путь к его исполняемому файлу.

При текущей проверке скачивание WebKit заблокировано сетевой политикой (HTTP 403 от CDN). Проверки на настоящем iPhone не проводились.

Опциональная проверка WebKit (это движок Safari, **не настоящий iPhone**):

```sh
npx playwright install webkit
TEST_WEBKIT=1 npm test
```

Для WebKit в Linux могут требоваться системные библиотеки (`npx playwright install-deps webkit`). Загрузка браузера требует доступа к CDN Playwright. Уменьшение движения учитывается через `prefers-reduced-motion`; все основные действия имеют кнопки, жесты необязательны.

## Структура

- `src/App.tsx` — переходы между сценами и награды.
- `src/components/Art.tsx` — оригинальные масштабируемые SVG-персонажи, остров и предметы.
- `src/components/AdventureScenes.tsx` — пять приключений.
- `src/components/ArcadeScene.tsx` / `src/lib/arcade.ts` — две дополнительные игры, механика совпадений, каскады, объединения и сохранение.
- `src/components/GardenScenes.tsx` — сад, письмо, комплименты, счётчик и объятия.
- `src/components/UI.tsx` — диалоги, звёздочки, аудио-переключатели и конфетти.
- `src/lib/` — хранение, оригинальная музыка, даты.
- `src/styles.css` — адаптивная вёрстка и анимации; Tailwind подключён через Vite.

Шрифты Nunito и Lora установлены локально через Fontsource; запросов к Google Fonts нет. Шрифты распространяются по SIL Open Font License (см. лицензии пакетов). Внешние фотографии, аудиозаписи, аналитика и платные сервисы не используются.
